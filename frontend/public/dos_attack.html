Availability in the CIA triad

A DoS attack targets Availability. Nothing is altered or leaked; the monitoring system simply stops receiving data it needs. Operators lose visibility exactly when they need it.

Heartbeat monitoring

Each meter sends a telemetry packet with a heartbeat and an increasing sequence number about every 1.2 s. If the server hears nothing for longer than the timeout, the meter becomes STALE, then OFFLINE at twice the timeout. Gaps in sequence numbers reveal exactly how many packets were lost.

Telemetry freshness

Silence is not zero. Electricity keeps flowing through the feeder, so the server keeps the last known value, flags it STALE, and shows its age. Writing 0.00 kW would create false billing and hide real consumption.

DoS vs physical bypass

A bypass shunts current around the meter while its communication stays healthy: telemetry looks fresh but the numbers are too low. A DoS keeps the meter's measurement correct but cuts the link, so telemetry goes missing. One shows wrong data, the other shows no data.
